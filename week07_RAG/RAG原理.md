# RAG 四步原理与防幻觉思考
## 一、 RAG（检索增强生成）的四步走
1. **加载（Load）**：把我们的学科资料（比如《HSK等级标准节选》）读进程序里。
2. **分块（Split）**：把长篇大论切分成一小段一小段的（比如 500 字一块），这样方便电脑精细查找，不会因为太长而抓不住重点。
3. **向量化（Embed）**：电脑不认识汉字，所以我们调用 `nomic-embed-text` 模型，把每一块文字变成一串数学数字（向量）。意思越相近的段落，这串数字的坐标就越靠近。
4. **检索+生成（Retrieve + Generate）**：当用户提问时，把问题也变成向量，去库里算出最相似的那几段原文找出来。最后，把找出来的原文和用户的问题拼在一起，交给大模型（`llm.ask`）生成最终答案。

## 二、 为什么检索之后答案就靠谱了？
**根本原因：大模型从“凭记忆瞎猜”变成了“看着资料说”（开卷考试）。**

* **裸答（无资料）**：大模型就像一个博学但记性不好的人，遇到自己没见过或者记不清的具体数字（比如 HSK4 到底多少词汇），它为了迎合你，就会一本正经地胡编乱造，这就是**“幻觉”**。
* **RAG（带资料）**：我们通过检索，把真实的原文片段当作“参考资料”硬塞进提示词里，并强制要求模型“资料里没有的就不许说”。模型有了真实依据，自然就不会乱编了，而且答案有据可查，可以追溯来源。
