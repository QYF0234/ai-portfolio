## 【适用说明】

## 【最佳示例】
10分钟课堂互动活动：《愚公移山——把任务完成！》
适用对象：HSK3-4级
活动目标：学生能在《愚公移山》情景中，正确说出“S+把+O+V+补语/其他成分”的句子。
活动形式：小组竞赛+任务卡+动作表演
准备：任务卡若干、白板、计分表、小奖章（可用贴纸）

一、情景导入（1分钟）
老师：“愚公要移山。他先做什么？他把石头搬走，把土运到渤海。今天我们是愚公移山队，要用‘把’字句完成任务！”
板书结构：
S + 把 + O + V + 补语/其他成分
愚公 把 石头 搬 走 了。
我们 把 土 运 到渤海。

二、规则说明（2分钟）
1. 全班分4组，每组是一个“愚公移山队”。
2. 老师当“天帝”，出示任务卡。
3. 每组轮流派一名学生，在10秒内说出一个完整的“把”字句。
4. 句子必须包含：谁+把+什么+动作+结果/地方。
5. 说对得1分；加上动作表演再得1分；帮别人纠正得1分。
6. 最后得分最高的组获得“天帝奖章”。
错误提醒：
X 愚公搬走石头。 ✓ 愚公把石头搬走了。
X 愚公把石头搬。 ✓ 愚公把石头搬到渤海。

三、示例与带读（1分钟）
老师出示卡片，学生齐说：
任务卡：愚公/石头/搬/走 -> 正确句子：愚公把石头搬走了。
任务卡：我们/土/运/到渤海 -> 正确句子：我们把土运到渤海。
任务卡：愚公/山/挖/平 -> 正确句子：愚公把山挖平了。
任务卡：智叟/门/关/上 -> 正确句子：智叟把门关上了。
任务卡：你/工具/放/在地上 -> 正确句子：你把工具放在地上。
任务卡：他们/树/拔/出来 -> 正确句子：他们把树拔出来了。

四、小组竞赛（5分钟）
老师快速出示8-10张任务卡，小组轮流回答。卡片可分三类：
1. 结果补语：走、完、平、开、上、好（例：愚公把山挖平了。）
2. 趋向补语：来、去、出来、进去（例：他们把石头搬出来了。）
3. 介词短语：到、在、给（例：愚公把土运到渤海。我把工具放在地上。）
加分动作：说句子的学生可以边做动作边说。
HSK4扩展：鼓励能力强的学生加“先……再……”（例：愚公先把石头搬走，再把土运到渤海。）

五、总结与作业（1分钟）
全班齐说两句：“愚公把山挖平了。”“我们把困难搬走了！”
作业：用“把”字句写3句话，描述愚公移山。
例：1. 愚公把石头搬走了。 2. 他们把土运到渤海。 3. 智叟把门关上了。
评选：得分最高的组获得“天帝奖章”。老师快速纠正1-2个典型错误，结束活动。
