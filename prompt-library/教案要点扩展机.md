# 教案要点扩展机

## 【提示词】
### 角色
你是一名国际中文教师，擅长教学设计与课堂活动编排。
### 任务
将简要的教案要点，扩展成一份完整的45分钟教案。
### 要求
必须包含：教学目标（语言知识、语言技能、文化情感、学习策略）、教学重难点、教学过程（含时间分配）、板书设计。教学过程要详细写出教师活动、学生活动和设计意图。
### 示例
（将以下教案结构作为参考范例）
### 变量输入区
（在此处粘贴你的教案要点，如：1.导入：讨论困难。2.讲解：对比愚公和智叟。3.操练：分角色朗读。4.活动：辩论赛。5.作业：写短文。）

## 【适用说明】
粗要点一键变完整教案（PPT第13页场景②）。适用于备课时间紧张时，快速生成可直接使用的教案框架。

## 【最佳示例】
《愚公移山》45分钟教案

一、基本信息
课型：HSK5阅读与口语综合课
教学对象：HSK5水平国际学生
课时：45分钟
教学内容：《愚公移山》人物形象对比与寓意理解
教学方法：任务型教学法、交际法、对比法、角色朗读、辩论
教具准备：PPT、课文、人物卡片、辩论卡、计时器、评价表

二、教学目标
1. 语言知识目标：理解重点词语和句子（如“惩山北之塞，出入之迂也”等）；能用现代汉语概括人物态度和理由。
2. 语言技能目标：能分角色朗读，注意语气、停顿和感情；能用“我认为……因为……”“虽然……但是……”等句式表达观点并辩论。
3. 文化情感目标：理解寓言寓意；体会中国文化中“不怕困难、造福后代、集体努力”的精神。
4. 学习策略目标：通过对比表格梳理人物形象；通过角色朗读和辩论加深理解。

三、教学重难点
重点：对比愚公和智叟的人物形象；理解寓言寓意。
难点：文言词句转现代汉语；辩论中清楚表达理由，礼貌反驳。

四、教学过程
（一）导入：讨论生活中的困难（5分钟）
教师活动：提问“生活中你遇到过像大山一样的困难吗？”；板书关键词：困难—坚持/放弃—改变/适应；请2-3名学生分享。
学生活动：两人小组讨论1分钟；自愿分享经历。
设计意图：联系生活经验，激活背景知识，自然导入主题。
（二）讲解：对比愚公和智叟的人物形象（12分钟）
教师活动：请学生默读找出写愚公、智叟和妻子的句子；PPT展示对比表格并引导填写；用现代汉语解释重点句；提问智叟和愚公对山的看法有何不同；总结愚公目光长远、智叟目光短浅、妻子是现实担忧。
学生活动：默读、找句子、填表格；回答问题，用现代汉语复述人物观点。
设计意图：通过对比分析，帮助学生把握人物形象和课文主旨。
（三）操练：分角色朗读（10分钟）
教师活动：分组（4-5人一组，角色包括旁白、愚公、妻子、智叟、子孙/邻居）；示范语气（愚公：坚定、平静、有信心；妻子：疑问、担心；智叟：嘲笑、轻视）；学生练习3分钟；请两组上台展示；其他学生用评价表评价。
学生活动：小组内分角色练习；上台朗读；互相评价。
设计意图：通过朗读体会人物情感，加深对人物性格的理解。
（四）活动：小型辩论赛“移山还是搬家”（13分钟）
教师活动：提出辩题；分组（正方移山，反方搬家，每组3名辩手）；提供语言支架（我认为……因为……等）；控制辩论流程（准备2分钟，陈词各1分钟，自由辩论4分钟，总结各1分钟，点评2分钟）；教师总结（搬家更省力，但移山赞美不怕困难的精神，两者并不完全矛盾）。
学生活动：小组讨论，准备理由；辩手发言，其他学生补充；评委记录并评选“最佳辩手”。
设计意图：培养思辨能力、口语表达能力和合作能力。
（五）总结与作业（5分钟）
教师活动：总结板书（愚公精神=目标明确+不怕困难+坚持不懈+长远眼光）；布置二选一短文（150-200字），要求用上“坚持不懈”“不怕困难”“只要……就……”中的至少两个；下节课请3-5名学生分享。
学生活动：记录作业；有疑问可提问。
设计意图：读写结合，把课文精神迁移到学生生活表达中。

五、板书设计
愚公移山
愚公：年且九十；坚定；目光长远；子子孙孙无穷匮，山不加增；天帝感其诚
智叟：笑而止之；嘲笑；短视；残年余力，不能毁山之一毛
妻子：献疑；担忧；现实
寓意：坚持不懈，不怕困难，目光长远
