## 【最佳示例】
语法点：“把”字句
1. 语法公式：S + 把 + O + V + 补语/其他成分
2. 使用条件：强调对宾语的处理或结果。
3. 常见错误：X 愚公搬走石头。 ✓ 愚公把石头搬走了。
4. 配套练习：请把下列词语连成“把”字句。
   (1) 愚公 / 石头 / 搬 / 走
   (2) 我们 / 土 / 运 / 到渤海
答案：(1) 愚公把石头搬走了。 (2) 我们把土运到渤海。
